# BMI Tracker and User Management - Frontend Client

This repository contains the clean client-side frontend files for the BMI Tracker and User Management application.

## 📁 Files Included

- **`index.html`**: Core structure for authorization screens (Sign In, Register, Password Reset) and the interactive user dashboard.
- **`styles.css`**: Styling layouts, modern dark/light mode properties, responsive grid systems, and glassmorphism styling parameters.
- **`app.js`**: Frontend JavaScript handling DOM actions, user input validations, unit toggles (KGS ↔ LBS, CM ↔ Inches), profile switcher panels, and animated visual charts via **Chart.js**.

## 🚀 How to Run the App
Since these are static files, you can open and run this application immediately by double-clicking **`index.html`** to open it in any web browser.

By default, the frontend is configured to communicate with the REST API backend server at `http://localhost:5000` (or local port `8080`).
